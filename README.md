# 🧮 Calculator

A simple and interactive Calculator built with HTML, CSS, and JavaScript featuring basic arithmetic operations, a clean UI, and responsive button interactions.

## ✨ Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear button
- Prevents consecutive operators
- Error handling for invalid results
- Clean HTML, CSS & JavaScript code
- Beginner-friendly project

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
